## 一、生产基线（本轮优化的对照栈）

V3 默认参数（docs/v3-best-plan.md §3）：领先窗 10 / 正收益过滤窗 3 / 共振窗 10 /
全A回撤窗 10 / 半衰期 (5,3,2)@阈值(2%,4%) / Top3 / 最短持有 3 / 止损 5% /
冷静期 1 / T+1 收盘执行（exec_lag=1）/ 决策成本 10bp（0/30bp 报告口径）。

5 相位中位基线（10bp）：总收益 +36.41%，回撤 −21.67%，夏普 0.702，
变更 84 次，止损 7 次，空仓 14.3%。

**关键背景差异**：V3 的相位敏感性远低于 dyn5 基线（5 相位 +44%~+61% vs
dyn5 +29%~+152%）——每日检查 + 最短持有使路径快速同步；V3 文档 §9 的
"建仓错日 0/1/2 一致"在本机精确复现。相位协议仍保留（防单相位运气），
但检验力注记与 dyn5 不同。

## 二、验证协议（沿 minute-exec-design.md §三/§四，预注册）

- 相位：5 个相邻交易日起点 {2024-12-27, 12-30, 12-31, 2025-01-02, 01-03}，
  全窗至 2026-09-18；中位数为主判据。
- 决策成本 10bp；网格轮报告 0bp 对照；R2 分钟层另用 1 年窗（见 §三.R2）。
- 单轮单改动：每轮只动一个轴（相对当前生产栈），逐轮累积采纳。

**预注册判据**（先于回测固定）：
- **采纳**：5 相位中位 Δ总收益@10bp ≥ +2pp，且 ≥4/5 相位 Δ≥0，且中位
  Δ回撤 ≥ −1pp（不允许用回撤换收益）。
- **NEUTRAL**：|中位 Δ总收益| ≤ 2pp 或相位方向不一致 → 不采纳，记档。
- **HARMFUL**：中位 Δ总收益 < −2pp → 排除。
- **网格形态约束**：参数网格（R1/R3–R8）的采纳点须呈剂量-响应形态或
  参数邻域连续（相邻网格点至少一点 Δ≥−1pp），孤峰不采纳；并列取参数
  离 V3 规格值最近者（简约性优先，防过拟合）。
- **最终择优分数**（R10 复核用，V3 文档 §11 相位中位化）：
  score = med(总收益@30bp) + min(med(2025@10bp), med(2026@10bp)) − |med(回撤@10bp)|。

## 四、风险与边界（全程标注）

1. 2025—2026 数据已参与规格制定与本轮 10 轮筛选，**全部数字为样本内**；
   V3 文档自身已警示（§12），本协议的相位中位只能防相位运气，不能防过拟合。

   （无冲击/涨跌停/跟踪误差）；R2 分钟层隐含"可按分钟价成交"的更强假设。
3. 概念目录为 2026-09-19 快照回填，幸存者偏差沿基线标注。
4. 每轮结论判定须引用本文件判据原文；网格孤峰与方向不一致一律不采纳。
