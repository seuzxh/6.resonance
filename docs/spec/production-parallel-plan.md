# V4.4 生产并行规格：D3 三锚动选 + D2 双锚动选

决策日期：2026-10-05。本规格只增加 D2 生产并行纸面轨，不修改 V4.4 引擎参数，不新建引擎文件，不改变原四条样本外评价轨的预注册判据。

## 一、身份

| 轨道 | 锚池 | 身份 |
|---|---|---|
| D3 | 深证成指、国证2000、科创50 | 现行生产主轨 |
| D2 | 深证成指、中证1000 | 生产并行纸面轨 |

## 二、冻结参数

两轨均使用 `ops/signal_daily.py FROZEN`：

```python
V3Params(topk=3, daily_top=5, hl_source="leader", cost_bp=10.0,
         exec_price="open")
```

其余默认值保持 V4.4：10 日选锚、3 日闸门、10 日上涨共振窗口、5/3/2 日半衰期档位、最短持有 3 日、5% 收盘止损、冷静期 1 日、尾盘 24 根 5 分钟 K线重排。

## 三、运行纪律

1. D3 与 D2 每日独立重放，不共享持仓、入场价、净值或成本。
2. 两轨均从官方样本外起点 2026-09-29 空仓起步。
3. D2 不进入原 A9（九池对照）、B13（历史十三池名义对照）、C1（深证成指单锚）、D3（三锚主轨）四轨预注册裁决；其生产并行裁决另按部署文档执行。
4. 评价期内禁止修改锚池、信号参数、执行参数和成本假设。
5. 切换、停止或降权重必须由人工裁决；运行器与审计智能体无权修改。

## 四、适用边界

本仓库没有实盘下单接口。概念指数不可直接交易，单边 10 个基点是统一压力假设。概念目录存在幸存者偏差。历史拼接展示段只能作为样本内上界解释，不能当作独立样本外证据。

参数标识符释义：`topk`（续持前三名）、`daily_top`（日线前五名预选）、`hl_source`（半衰期按领先指数定档）、`cost_bp`（单边成本基点）、`exec_price`（成交价时点）。
