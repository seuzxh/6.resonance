# 指数—概念上涨共振策略：最佳方案 V3

## 1. 文档状态

- 版本：V3
- 回测区间：2025-01-01 至 2026-09-18
- 数据来源：同花顺 iFinD 历史指数数据
- 研究范围：13个宽基/风格指数与约390个概念指数
- 组合方式：单组合、100%资金，同一时间最多持有一个概念指数
- 参数搜索：保持最短持有期3日不变，完成189组粗网格和2,268组精细网格，共2,457组

> 本方案由2025—2026样本内参数搜索产生。回测结果不代表未来收益；正式使用前应冻结参数并进行独立样本外验证。

## 2. 策略目标

先识别当前相对最强的宽基或风格指数，再选择与其在上涨方向上同步程度最高的概念指数。共同下跌不计入共振评分，避免将系统性下跌误判为有效共振。

## 4. 信号规则

### 4.1 选择领先指数

在指数池中计算每个指数近10日复合收益率，选择收益最高者作为领先指数。领先指数近3日复合收益率必须大于0，否则不建立新的概念仓位。

### 4.2 筛选候选概念

候选概念近3日复合收益率必须大于0；未满足条件的概念不参与共振排名。

### 4.3 上涨共振评分

只在领先指数当日收益大于0的交易日计算共振，领先指数与概念共同下跌的日期权重为0。

```text
上涨同步率_i = Σ[w_t × I(领先指数上涨且概念i上涨)]
               / Σ[w_t × I(领先指数上涨)]

上涨捕获率_i = Σ[w_t × max(概念i收益率, 0)]
               / Σ[w_t × max(领先指数收益率, 0)]

上涨共振分数_i = 上涨同步率_i
                 × sqrt(clip(上涨捕获率_i, 0, 2))
```

其中 `w_t` 为指数衰减权重，观察窗口为近10个交易日。

## 5. 动态半衰期

计算同花顺全A近10日路径中的最大回撤：

```text
最大回撤 <= 2%：半衰期 = 5日
2% < 最大回撤 <= 4%：半衰期 = 3日
最大回撤 > 4%：半衰期 = 2日
```

回撤越深，旧周期权重衰减越快，以便更快识别新的上涨共振。

## 6. 持仓和换仓规则

1. 空仓且满足入场条件时，买入上涨共振排名第一的概念。
2. 建仓后至少持有3个交易日。
3. 从第4个交易日起每日检查排名。
4. 原持仓仍位于Top3时继续持有。
5. 原持仓跌出Top3时，更换为当日排名第一的概念。
6. 若没有满足正收益过滤的候选概念，则退出至现金。
7. 同一时间只持有一个概念，不拆分为多个错峰子组合。

## 7. 止损与重新入场

- 固定止损线：相对本次入场价格下跌5%。
- 止损每日检查，不受3日最短持有期限制。
- 止损信号按正常时序在T+1收盘执行。
- 止损执行后冷静1个交易日。
- 冷静期结束后，若领先指数和候选概念仍满足条件，可重新产生入场信号。

## 8. 交易成本口径

- 买入或卖出分别按单边成本计提。
- 概念A直接切换至概念B视为一卖一买，共计两次单边成本。
- 分别测试0、10bp和30bp三种成本情景。

## 11. 网格选择标准

```text
稳健性分数 = 30bp成本总收益
             + min(10bp下2025收益, 10bp下2026收益)
             - abs(10bp下最大回撤)
```

该标准偏好成本压力下仍有收益、两个年度均有效且回撤较低的方案，不按零成本最高收益直接选择。

## 12. 使用限制与后续验证

1. 2025—2026数据已经参与参数筛选，不能视为独立样本外区间。
2. 共进行了2,457组组合校验，存在多重试验造成的样本内高估风险。
3. 概念指数通常不是直接交易资产，实际执行需映射到ETF、股票组合或其他可交易标的。
4. 当前成本为统一压力假设，未单独模拟冲击成本、涨跌停、流动性和跟踪误差。
5. 下一步应冻结本页参数，补充更早年份的概念指数数据并进行滚动样本外验证。
6. 5分钟K线重排层尚未完成历史回测，不属于本版V3已验证方案。
