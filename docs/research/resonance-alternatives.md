# 共振寻优替代机制：预注册与结果

2026-10-03 注册；本文件先于本轮结果生成。实施脚本为
`research/resonance_alternatives_core.py`（规则与原引擎适配）和
`research/resonance_alternatives_run.py`（只读数据与矩阵运行）。

## 一、问题与边界

上一轮单锚概念策略表现选锚与软占用惩罚失败。本轮分别检验三种机制，
不叠加寻优：波动率归一化能否减少高波动指数的动量优势；多锚共同排序
能否保留跨锚一致的概念；硬上限能否以可接受的绩效代价控制锚占用。
这三项均没有重复上一轮质量分调参，也不等同于已否决的位次变换或相关性选池。

这是历史样本内上界研究，不是新的样本外检验。概念指数不可直接交易，
成本为统一压力假设；存活概念目录回填存在幸存者偏差。严禁读取2026-09-18
以后行情参与计算，不改变2026-09-29开始的样本外评价期参数或运行代码。

## 二、共同口径

- 候选顺序固定：深证成指、国证2000、科创50、中证1000、创业板指。
  所有同分按此顺序；概念同分按代码升序；退役指数入口自检。
- 使用现行开盘执行形态：信号日收盘确定，下一交易日开盘成交；单概念
  持仓、日线10日上涨共振、领先指数自身回撤决定半衰期、近3日正收益闸门、
  日线前5后做24根分钟重排、前3名持仓缓冲、最短持有3日、5%固定止损、
  冷静1日。原始持仓与止损基准由原引擎连续维护，不拼接净值。
- 主窗口：2022-06-01起的前5个交易日分别开始，至2026-09-18；早期窗口
  同样开始至2024-12-31；近期窗口从2025-01-01以后前5个交易日分别开始，
  至2026-09-18。各账户独立空仓开始，历史指标和硬上限记录连续预热。
- 单边成本10个基点为主（1个基点=0.01%），0与30个基点为压力对照；
  换仓计双边。结果取5相位中位，同时保留逐相位配对差和后续成交收敛日期。
- 对照为深证单锚、现行三锚、深证与中证1000双锚、五指数原始动量动选。
  双锚为主比较基准；五指数动选为机制比较基准，不把击败弱对照当成采纳。
- 不新增网络请求。使用主仓只读数据，按深证交易日历对齐，输入文件摘要
  在开始与结束复核；保持原数值精度。

## 三、三组独立规则

### A：风险调整动量选锚

每日以近10日复合收益除以近若干日日收益的样本标准差，选择最大者。
波动观察窗为10、20、40、60日，20日为事先指定中心；10与40日为邻域，
60日为边缘探针。分母下限0.0001；完整价格与收益窗口不足者不参加。
先选锚再应用所选锚原3日闸门，不追加正分资格或占用惩罚。
分数不是夏普比率，不解释为未来预测能力。

### B：多锚共同排序

原始10日动量排名第一的指数仍控制入场闸门；它闸门关闭时整体无候选，
不因为其他指数上涨而重新开启。按原始动量取前2、3、4、5个指数，3个为
事先指定中心，2与4个为邻域，5个为边缘探针。参与者还须通过自身原3日
闸门且当日日线榜非空；每个参与锚用自身半衰期计算原始上涨共振。

各参与锚对同一概念的原始分数等权算术平均，概念须存在于所有参与榜；
只对平均分排序，不做位次变换。日线取前5后，在相同概念集合上分别计算
各参与锚的原分钟分数，再等权平均。同步率与捕获率列分别平均仅供诊断，
最终分数是各锚分数的平均，不是两列平均值重新相乘。

仅1个参与锚时使用该锚原榜并计数；无参与者时无候选。分钟任一参与锚
窗口缺失，或任一分数为空，整组降级到共同日线前5；概念分钟不足者剔除，
剩余不足2个时降级到共同日线前5。沿用原24根跨日数据供给，不静默修正
陈旧窗口；缺锚、剔概念、稀疏、陈旧锚与陈旧概念分别计数。

参与权重属于评分贡献，不是资金仓位或选锚频率；逐日记录全部贡献权重。
至少2锚参与时单锚权重不超过一半，但1锚降级仍可能集中，不能宣称无条件
消除单锚主导。原始领先指数仅作为诊断标签，不能代替贡献明细。

### C：锚占用硬上限

在原五指数动量选择上单独加约束：包含当日在内的最近60个交易日，每个锚
选择天数不超过24、36、48天，分别对应40%、60%、80%；60%为中心，另外
两档为邻域。选择时统计此前59日，按动量顺序选尚有额度者，再应用其原
3日闸门。闸门关闭仍计作被选锚日，因为限制的是选择权，不是持仓。
无额度或无完整动量候选时不指定锚，进入原引擎无候选处理并计数。
历史记录从完整日历首日开始，早期不足60日的位置计空缺；各评价相位不
重置记录。硬上限会迫使选择次优分数，代价必须显式报告。

## 四、判据与停止规则

三组中心配置分别与双锚比较：主窗口10个基点的配对总收益差中位至少
+2个百分点，至少4/5相位胜出，配对最大回撤差中位不低于−1个百分点
（回撤为负数）；早期和近期的配对收益差均不低于−2个百分点；30个基点
主窗配对收益差仍为正。任一不满足，不列为待采纳规则。

中心配置通过后，至少一个预定邻域配置必须同向通过上述绩效条件，才可
进入后续验证；禁止结果出来后把网格冠军替换为中心配置。年度收益、交易
次数与现金日必须报告，不以总收益遮盖年度失衡。相位收敛不能算独立重复。

针对原用户集中度要求，A/C还须使最大60日锚占用率的相位中位数相对
原五指数动选至少降低10个百分点，且报告有锚日条件占用率与最长连续天数。
B报告最大60日平均贡献、单锚参与日数及无参与日数；分母含无贡献日，并
另报有参与日的条件贡献，避免以更多空缺掩饰集中。二者不能混作同一统计。

预先安排纯日线诊断：仅双锚与A/B/C三个中心配置，10个基点、三窗口、
5相位；共60次。日线诊断关闭前5截断及分钟重排，保留原全部日线候选，
不重调参数；用于识别分钟覆盖混杂，不替代主矩阵。主矩阵15配置×3成本
×3窗口×5相位，共675次。

### 补充注册：固定池交互复验（先于第二轮结果）

首轮只在五指数池施加新规则；该池本身早期表现弱，不能把失败泛化到
任何池。遵循实验手册“池与组件存在交互”约束，只在既定双锚和三锚池
分别复验相同机制，不更换数据、不搜索池组合、不改首轮结论。

- 对每个池，风险调整动量仍为10/20/40/60日，20日中心；硬上限仍为
  40%/60%/80%，60%中心。双锚40%时两者额度合计不足窗口天数，允许出现
  无锚日并计数，不突破上限或临时放宽资格。
- 多锚共同排序使用池内动量领先者闸门与该池内参与者：双锚最多2锚；
  三锚最多2或3锚，3锚中心。所有分数合并与降级完全沿用第三节。
  双锚2锚是结构性配置，没有可用的参与数量邻域；即使通过绩效，也仅列
  为待独立复核观察项，不能绕过稳健性要求直接采纳。
- 主对照仍为原双锚，同时比较各自原池。成本、窗口、相位、判据均沿用
  第四节；双锚9配置、三锚10配置，合计855次主形态回测。
- 预先安排每池原规则及三个中心、10个基点、三窗口、5相位的纯日线
  诊断，共120次。合计975次，不与首轮重复项拼成独立证据。
- 集中度改善线与各自原池比较；共同排序始终单列贡献，不伪装成单锚
  占用率。所有较晚研究仍是已见历史的样本内上界，不能称样本外。
- 如果两轮均没有符合全部判据的中心及邻域，停止本次三机制研究并登记
  负结论；不得继续事后增加参数或重组池来追逐正值。
