# 预注册：rank 因子族探索（截面位次 / 时序分位 / 位次迁移）

> 2026-09-29 预注册，同日执行。性质：**未预注册不作采纳**——本设计先行
> 冻结因子清单与判据，执行结果无论正负均登记；采纳需另行预注册对照实验。
> 实施脚本：`research/qlib_route_a/qlib_explore_rank.py`（同名同构）。

## 一、动机与现状（为什么是它、为什么现在没被覆盖）

评价端自始用 Spearman Rank IC，但因子端从未做过 rank 变换。已扫过的
20 条分位族（Alpha158 的 RANK/RSV/QTLU/QTLD，outputs/qlib_ml/
alpha158_ic.csv）全部**只作用于价格自身**且全窗 |t|≤2.17 未过线。
未被覆盖的对象：动量/波动/成交额/共振分（score）的截面位次、时序分位
与位次迁移。桥文件 daily_factors.parquet 已有 `rank` 列（当日共振榜
名次），但它是 score 的完全单调变换，IC 与 score 等价，不构成独立信息。

机制假设（一句话）：相对全市场的**位次**与相对自身历史的**分位**承载
绝对值因子不含的「相对位置」信息；**位次的一日迁移（ΔRank）**承载
加速度信息。截面 rank 化本身不改变单因子 Spearman IC（单调不变性），
故新信息集中在时序分位与位次迁移两族——对照组用于验证该不变性。

## 二、因子清单（冻结 13 条）

记 `MOMk=close.pct_change(k)`、`VOL20=日收益.rolling(20).std`、
`AMT20=amount.rolling(20).mean`；`XR(·)`=当日截面百分位位次（全概念
池内）、`TSR(·,N)`=rolling(N).rank(pct) 时序分位；score 取桥文件
（仅信号日非空，位次在当日候选集内计算）。

新信息族（9）：
| 因子 | 定义 | 方向假设 |
|---|---|---|
| TSR_C20 / TSR_C60 | 收盘价时序分位 | 正（趋势延续） |
| TSR_MOM10_60 | 10日动量的60日时序分位 | 正（动量相对自身历史强化） |
| TSR_VOL20_60 | 20日波动的60日时序分位 | 负（波动放大=风险） |
| DR_MOM5 / DR_MOM20 | 5/20日动量截面位次的一日变化 | 正（位次上移=资金流入） |
| RANKGAP_20_5 | 20日动量位次 − 5日动量位次 | 负（短期落后于中期=补涨 / 正=强者恒强，两可，仅登记） |
| DR_SCORE | 共振 score 截面位次的一日变化 | 正 |
| XR_GAP_SCORE_MOM5 | score 位次 − 5日动量位次 | 正（共振领先动量=增量信息） |

对照组（4，验证口径与不变性，不计入多重比较候选）：
`XR_MOM10`（预期全窗 IC≈Alpha158 ROC10 同号同量级）、`XR_VOL20`、
`XR_AMT20`（流动性位次，新观察）、`BR_RANK`（桥 rank 列，预期与
score 的 IC 数值相等、符号相反——完全单调变换 sanity）。

## 三、口径（与既有扫描严格一致）

- universe：5min 覆盖概念池（与 alpha158 扫描同源：目录 ∩ 5min 任一
  bar，`ParquetData`）；入口过 `config.assert_no_retired` 自检。
- 窗口：2025-09-26~2026-09-23（跳过头 4 日 close-only 段）；时序分位
  的 lookback（≤60 日）用全历史预热后切片，无未来数据。
- 标签：LABEL1/2/5 = T+k 收盘对收盘（预测目标定义，不随 V4.4 成交
  口径变）；T 日因子 → 最早 T+1 计收益。
- 切分：SEGMENTS 冻结（train 至 2026-05-29 / test 2026-08-03~09-23），
  报全窗 + test 段双口径。

## 四、判据（预注册，执行前冻结）

1. **过线**：全窗 |t| ≥ 2.89（Bonferroni：13 检验 α=0.05/13 双侧近似）
   **且** test 段同号 |t| ≥ 1.5 **且** L1→L5 衰减不翻号 → 记「候选」；
2. 3.5 严线（157 扫描沿用）同表并列报告；
3. 对照组（2026-09-29 执行时修订）：截面位次化不改变 Spearman IC——
   **内部不变性**校验：XR_MOM10 与原始 MOM10 全窗 IC 差 <0.005、BR_RANK
   与桥 score 的 IC 绝对值差 <0.005。原稿写的「XR_MOM10≈Alpha158 ROC10」
   系口径错误（该扫描的 ROC10 是 5min 表达式=日末前 10 根 bar 动量，
   非日线 10 日动量，不可比），判据本身（§四.1/2）未动；
4. 多重比较：13×0.05 期望 ~0.65 个假阳性；正结论一律 L3 上界措辞
   （样本内、单一 regime、幸存者目录、概念指数不可直接交易）；
5. 负结论（全部不过线）→ 登记 playbook §三负结论表：分位/位次形态
   在本 universe 无增量。

## 五、预期边界

score 族因子覆盖 = 信号日占比（闸门失败日 NaN，自动剔出 IC 计算），
非 NaN 率单独上报；TSR 族前 N 日 NaN；都不构成混杂（IC 按日 dropna）。
