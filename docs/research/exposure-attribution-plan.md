# 预注册设计：风险暴露环节归因（阶段一）

日期：2026-10-04。本实验承接[开仓、空仓与仓位恢复路线](exposure-roadmap.md)的第一步，只做既有连续账单的描述性归因，不改变生产参数、不改变研究双锚、不运行新的候选策略回测，也不触发样本外（Out-of-Sample，OOS）程序。

## 一、机制问题

冻结研究双锚原策略已经包含近3日正收益闸门、最短持有参数、前三名续持缓冲、5%止损与止损后冷静期。本阶段先回答：历史亏损更集中在哪些入场来源、退出原因和阶段窗口，而不是先增加新的风险控制规则。若亏损主要由少数连续段或止损后再入场造成，后续才研究危险期参与控制；若亏损分散且换仓本身占主导，后续应优先检查排名换仓，而不是仓位恢复。

## 二、冻结对象与数据

- 研究对象：深证成指`399001.SZ`与中证1000`000852.SH`双锚原策略。
- 执行口径：信号日T（当日收盘形成判断）收盘判断，下一交易日T+1（执行日）开盘成交；单边成本10个基点（1个基点等于0.01%），换仓计双边成本。
- 相位口径：主窗口、早期窗口、近期窗口各5个相邻交易日起点；主窗口为2022-06-01相位族至2026-09-18，早期窗口截至2024-12-31，近期窗口从2025-01-02起首5个交易日。五相位可能后续收敛，本阶段只作描述性中位数，不当作独立样本。
- 输入账单：`outputs/anchor_selection/trades_{window}_dual_phase{1..5}.csv`与对应净值表。
- 行情补充：只读主仓`data/cache/daily_bars.parquet`中双锚日线，用于卖出后修复的描述；不在本工作树复制行情，不访问网络。
- 数据边界：历史只截至2026-09-18；概念指数不可直接交易，成本是统一压力假设，概念目录存在幸存者偏差。本阶段输出仍是样本内描述，不是效果承诺。

## 三、持仓段与指标定义

一笔完整交易从一个`entry`或`switch`打开的下一段开始，到下一次`switch`、`exit`或`stop`结束；`switch`同时结束旧段并打开新段。数据末仍持有的段标记为未平仓，不计入完整交易胜率并单独计数。

为避免把换仓中新买入成本计入旧段收益，旧段在`switch`日的终点净值先除以`1-单边成本`，再计算终点与起点净值差；`exit`和`stop`直接使用卖出后净值。该口径保留旧段双边成本，不把一次换仓拆成两笔独立胜利。

每个持仓段记录：

- 入场来源：`cold_entry`（空仓后首次入场）、`reentry_after_stop`（止损冷静期后再入场）、`switch_entry`（排名换仓入场）。
- 退出原因：`switch`（跌出缓冲换仓）、`exit`（候选榜为空退出）、`stop`（止损）、`open`（数据末未平仓）。
- 扣费完整交易收益、持有时长、所在年月、是否亏损、亏损幅度。
- 卖出后修复：亏损段结束后到下一次入场前，任一双锚自退出日收盘起的累计收盘收益曾达到或超过5%。该线沿用现行止损幅度，只用于描述“原策略空仓期间市场是否修复”，不作为新交易信号。
- 再入场结果：亏损段之后下一笔完整交易的扣费收益；若无后续入场则单独计数。

## 四、输出与停止条件

输出到`outputs/exposure_attribution/`：

1. `segments.parquet`：逐笔持仓段明细。
2. `group_summary.csv`：按窗口、入场来源、退出原因汇总的5相位中位数。
3. `window_summary.csv`：按窗口汇总的亏损、最长连亏、止损后再入场、修复与再入场结果。
4. `report.md`：结论、样本覆盖、边界与复现命令。

汇总指标包括完整交易笔数、胜率、中位收益、最差收益、亏损段数量、亏损对数收益合计、最长连亏、持有时长中位数、修复事件数与修复后再入场胜率。主窗口为描述主表，早期与近期只用于阶段对照；窗口之间存在重叠，不把三窗口合计当作独立样本。

本阶段成功标准是账单可完整重构、每个已结束持仓段有唯一来源与退出原因、未平仓与修复事件全部计数。任何账单顺序不合法、净值日期缺失或成本换算不能复算时，先停止并修复数据审计；不得改用其他窗口或口径后继续读取结果。本阶段不产生采纳结论，也不授权阶段二仓位控制实验自动开跑。

## 六、执行结果与收口（2026-10-04）

本阶段已执行完成，共重构1,768个持仓段，其中1,753段已结束、15段数据末未平仓；未平仓段只计数，不计入完整交易胜率。新增3条合成测试连同既有测试共57项全部通过。

在主窗口2022-06-01相位族至2026-09-18、T+1开盘执行、单边10个基点、5相位中位、样本内描述口径下，双锚原策略的完整交易胜率为59.09%；同一口径下，早期窗口为53.40%，近期窗口为68.06%。主窗口亏损最集中的环节是排名换仓入场后止损：该组完整交易中位数为9笔、胜率中位数为0.00%、亏损段对数收益合计为-0.544；排名换仓入场后空榜退出次之，该组完整交易中位数为38笔、胜率中位数为47.37%、亏损段对数收益合计为-0.500。

对主窗口192个“排名换仓入场后空榜退出”账面事件逐条复核，192个事件的信号日均由领先指数3日复合收益小于或等于0的闸门失败造成；这不是概念目录无标的或行情缺失。相位样本重叠，192是账面事件数而不是独立样本数。5%修复定义只是亏损段退出后、下一次入场前任一双锚自退出日收盘起的后续收盘累计涨幅阈值，沿用现行止损幅度，未参与寻优，也不触发交易。

结论：阶段一只完成损失环节定位，不产生任何风险控制规则采纳结论。后续阶段二应先做危险状态诊断，重点解释排名换仓后的共同危险状态；不得直接把本文归因表当作仓位控制效果，也不得重启已登记失败的资金闸门或机器学习入场方向。实施脚本与测试按项目规则先留快照、随后清理，正式结果与复现说明见`outputs/exposure_attribution/report.md`，本地数据表保留在`outputs/exposure_attribution/`。
