> 判断上，目标**提高胜率、降低回撤**。本文档为预注册实验方案（playbook

## 一、接口与指标实测（2026-09-25 探测，探测脚本 work/probe_moneyflow.py）

- 端点：`POST https://quantapi.51ifind.com/api/v1/high_frequency`（用户示例
  主机；ft.10jqka.com.cn 同样可用）。body 直传（无 reqBody 包裹），
  token 走请求头。**响应 content-type 为 text/plain 但 body 是 JSON**。
- 请求参数：`codes`（逗号分隔，可批）/ `indicators` / `starttime` /
  `endtime` / `functionpara:{Fill:"Original", Interval:"60"}`。
- **配额按 dataVol = 指标数 × bar 数 计**（响应字段 `dataVol`，上限
  `MaxPoints=50000`/请求）→ Interval=60（4 bar/日）比 5min（48 bar/日）省
  12 倍；且实测**小时 bar 合计与 5min 合计逐分相等**（399001.SZ 2026-09-24
  主动买大单额 61,384,357,000 两口径一致）→ 日总量用 60min 采集无损。
- 历史深度：**滚动 ~1 年**（最早可用 bar 2025-09-25 10:30；更早起始时间
  静默截断、无报错）。bar 结束时刻：60min = 10:30/11:30/14:00/15:00。
- 指标映射（API 实际拼写，`possitive` 为接口原始拼写非笔误）：

| API 指标 | 含义（截图中文序） | 实测语义 |
|---|---|---|
| buyVolume / sellVolume | 外盘 / 内盘 | bar 内流量，股 |
| trans_num | 成交次数 | bar 内流量，笔 |
| raise_num / fall_num | 上涨 / 下跌家数 | **bar 末快照**（非流量） |
| total_delegate_buy/sell_vol | 总委托买入/卖出数量 | bar 内流量，股 |
| active_buy/sell_large_amt | 主动买入/卖出**特大单**金额 | bar 内流量，元 |
| active_buy/sell_main_amt | 主动买入/卖出**大单**金额 | bar 内流量，元 |
| active_buy/sell_middle_amt | 主动买入/卖出中单金额 | bar 内流量，元 |
| possitive_* | 被动（对应档位/方向/量额） | bar 内流量 |

注意该 API 命名与习惯相反：`large`=特大单、`main`=大单。**主力净额
（传统口径 特大+大）= Σ(active_buy_large_amt + active_buy_main_amt) −
Σ(active_sell_large_amt + active_sell_main_amt)**。

## 二、假设与机制（一句话机制 + L1 正交性论证）

**H1（主假设）**：领先指数处于**主力净流出**时的价格共振信号质量更低
（上涨缺机构参与 → 出货/假突破），在入场侧追加资金闸门可过滤低质量
入场 → 提高胜率、降低回撤。

- **L1 挤占检查**：现役栈（V4.3）从动量闸门、半衰期、止损到分钟重排
  **全部只消费价格**，订单流维度未被任何层占用 → 正交性成立，不是
  "更快更紧"的既有功能复刻。与已证伪防御层（G 轮）的区别：防御层用
  **价格回撤**做 regime 过滤且作用于持仓检查日；本闸门用**订单流**且
  **仅作用于空仓入场日**（soft gate，不触发提前退出）——登记表未覆盖
  此条件（新数据维度 + 作用面不同）。
- **L6 对症性**：闸门跟随**当日领先指数**自身的资金状态（非全市场一刀切）。

**H2（次级，诊断用不进栈）**：宽度（涨跌家数比）与外内盘比包含附加
信息，用于事件研究分组；不单独作为 R1 栈变体。

## 三、数据与特征

### 3.1 采集（work/collect_moneyflow.py）

- codes = 399001.SZ / 000688.SH / 883404.TI / 883957.TI / 000852.SH（+
  399303.SZ 留零取证）；12 指标 = 上表除 trans_num/middle/delegate 外的
  金额与流量项（含 passive 特大/大额备扩展）；Interval=60；
  starttime=2025-09-20 → endtime=采集日 15:15。
- 每码 12×4×~245 ≈ 11.8k dataVol < 50k → **每码 1 请求**，共 ~6 请求。
- 产出 `data/cache/moneyflow_hourly.parquet`（长表 symbol/datetime/指标），
  附覆盖审计（首末日、零值码计数）。

### 3.2 日频特征（回测注入层，work/exp_moneyflow.py 内构建）

对每个 code 聚合到交易日 T（当日 4 bar 求和；快照类取 15:00 bar）：

- `net_big(T)` = 主力净额（特大+大主动净额，元）；`gross_big(T)` = 主力
  交易总额（四项绝对值和/2 的口径：买+卖额合计）。
- **主判定指标** `g3(T) = Σ_{T-2..T} net_big / Σ_{T-2..T} gross_big`
  （3 日滚动主力净流入占比，scale-free，跨指数可比）。
- 诊断备用：当日净额、`g1`、宽度比 raise/(raise+fall)（15:00 快照）、
  外内盘比 buyVolume/sellVolume（日合计）。

## 四、实验设计

### R1 主实验：soft 资金闸门（唯一改动轴）

- 栈 = V4.3 生产栈（`V3Params(topk=3, daily_top=5, hl_source="leader",
  minute_bars=24, stop_mode="close", exec_lag=1)` + 三锚池），
  **唯一改动**：空仓入场日追加条件 `g3(leader(T)) > τ`；持仓检查日
  **不受影响**（不提前退出、不影响换仓）。信号 T 收盘 → T+1 收盘成交，
  资金特征同属 T 日收盘信息集，无前视。
- 阈值网格 τ ∈ {off（对照）, −1%, −0.5%, 0, +0.5%, +1%}（双侧边缘外
  探针齐备，防 L2 孤峰）。辅助单点：当日净额>0（V-a 绝对额口径）、
  `g1>0`（V-b 当日占比口径）——只作稳健性参照，不作采纳依据。
- **降级链（预注册）**：leader=399303.SZ（无资金数据）→ 用 000852.SH
  中证1000 作**指定代理**（同为中小盘宽基，假设记档）；代理亦无数据 →
  闸门直通并计数 `flow_fallback_days`；T-2..T 窗口数据不完整 → 直通计数。
  敏感性：直通版（不代理）另跑一列对照。
- 窗口：**主判据窗 2025-09-29→2026-09-18**（flow 数据 09-25 起，3 日滚动
  窗完整覆盖），5 相位 = 2025-09-29/09-30/10-09/10-10/10-13（国庆休市
  跳过）；**副窗 2025-09-22 起 5 相位**（对齐 V4.3 已发布数字，头 3 日
  降级直通计数）。成本 10bp 决策，0/30bp 报告。
- 事件研究（诊断，独立于回测路径）：全部「闸门+候选合格」日（含持仓中
  不入场的日子），按 top1 概念**未来 5 日收益**分组（g3>0 vs ≤0；分
  leader），报均值/中位/胜率与绑定率（闸门实际拦截的入场日占比）。

### R2（条件开启：仅当 R1 达采纳线）

方向池（单轴逐个）：hard gate（持仓检查日资金恶化→退出现金，L1 高危
先验，须与止损层挤占证据对照）；宽度闸门；委托比；盘中 14:35 快照执行
联动（需补 5min 采集）。R1 证伪则 R2 不开。

## 五、判据预注册（沿 playbook §一协议）

1. **采纳线**：主窗 5 相位中位 Δ总收益 ≥ +2pp（vs 同窗 τ=off 基线）且
   ≥4/5 相位为正；回撤恶化 ≤1pp；止损/换仓数不恶化超 20%。
2. **拒绝线（HARMFUL）**：中位 Δ < −2pp 或回撤恶化 >3pp。
3. **形态约束**：τ 网格剂量-响应须单调或单峰平滑；τ=0 过线但 ±0.5%
   塌陷（相邻点 Δ<−1pp）→ 孤峰嫌疑，不采纳只记录（L2）。
4. **检验力标注**：逐日检查型策略各相位收敛为同一路径（§一.2.b），
   名义 5/5 实为 1 条路径；Δ 的显著性以事件研究为辅助证据。
5. **低绑定率解释规则**：若闸门实际拦截入场日 <5% 且 |Δ|<判据线 →
   结论记 **no-op（无作用）**而非"有效/无效"，避免把未处理当处理。
6. 事件研究判读：g3 分组未来 5 日收益差不显著（|差|<1pp 或样本过小）
   → 即使回测 Δ 达线也须降级为"待 OOS 验证"，不得直接采纳。

## 六、风险与限制（措辞预约束）

- 单窗口（2025-09~2026-09，成长牛 regime）样本内结论 = **上界口径**
  （L3）；2022-24 熊市**无资金数据**（滚动 1 年限制），regime 外推
  不可检验，采纳也不得宣称跨 regime 有效。
- 概念目录幸存者偏差、指数研究口径（10bp 统一压力假设）沿项目全局标注。
- 国证2000 代理（→中证1000）为未验证假设，敏感性对照必报。
- 若采纳：仅作为研究结论登记，生产/OOS 切换须用户决策（另行预注册）。

### §八.2 R4 预注册（2026-09-25，S 升格候选后的正交性裁决轮）

动机：S 的 +29pp 增益可能是"主力资金流对同期涨幅的机械相关"（动量
重复计费）。文献（残差资金流强度因子，IC 0.054/IR 3.96）与本项目共同
指向：剥离同期涨幅后再看资金因子是否有独立信息。**本轮不改任何栈参数，
只改 R3 重排所用特征**，全臂上报，不许挑报。

**特征定义**（信号日 T，概念 c；全部仅用 ≤T 数据）：
- ret3 = 概念近 3 日复合收益（日线 close）
- g3 = 3 日主力净流入占比（R3 原特征）
- resid3 = g3 对 ret3 的残差——**扩展窗 pooled OLS**（g3 ~ a + b·ret3，
  仅用日期 < T 的样本拟合；拟合样本 = 149 码并集全历史，并集由本窗
  Top5 出现决定属轻微微选择性，只影响拟合不影响标签，登记为口径注）
- xl3 = 3 日**特大单**净占比（只用 large 档，剔除大单里可能的游资盘）

**臂**（分位重排制，与 R3 的 τ 分档制解耦）：每日最终榜中**有特征值的
候选**里，把特征最差的 q 个降级（healthy-first 稳定重排，无特征概念
不动）；q ∈ {1, 2}（Top5 池内 20%/40% 两点小网格，供形态判读）：

| 臂 | 特征 | 目的 |
|---|---|---|
| QF | g3 | R3 的分位制再表达（构造效度对照） |
| QR | resid3 | **P1 主判**：残差化资金是否有独立信息 |
| QM | ret3 | **动量安慰剂**：若 QM 复现增益 → S=动量复读 |
| QX | xl3 | P2：特大单口径是否优于主力合计 |

**判据（预注册）**：
1. 正交性确认（P1 过线）：主窗 10bp 中位 Δ(QR) ≥ +2pp 且
   Δ(QM) < Δ(QR) − 5pp（安慰剂显著更弱）→ S 候选证据升级
   （resid3 或 g3 二选一进 OOS，取 Δ 高且形态稳者）。
2. 动量复读判定（P1 证伪）：Δ(QM) ≥ Δ(QR) − 2pp → S 候选**降级**，
   不进 OOS，登记"S≈动量重复计费"。
3. 中间地带（+2pp 内）：结论记"混合"，S 维持原候选状态（τ=2/2.5），
   不升级不降级。
4. QF 应为正（构造效度）；QX 为 P2 变体：**收紧线 Δ ≥ +3pp 且 ≥ QF**
   （同批多重比较惩罚）才可替换特征，否则只记录。
5. 形态：q=1 vs q=2 不许翻符号；回撤恶化 ≤2pp（沿用户放宽线）。
6. 事件研究补充：日度 Top5 内 Spearman(g3, ret3) 分布与 resid3 分组
   fwd5 差，作为回测判读的辅助证据。
