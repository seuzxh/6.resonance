## R3 持仓缓冲 topk ∈ {1,2,3,4,5}

```
topk1 +24.98%/-25.55% | topk2 +27.50%/-25.55% | topk3(规格) +36.41%/-21.67%
topk4 +33.40%/-21.52% | topk5(≡topk4) +33.40%/-21.52%   （10bp 中位 total/dd）
```

判定：维持 topk3。1→2→3 单调升、3→4→5 回落，剂量-响应单调，规格值为峰；
topk4/5 路径完全重合（Top3 之外的名次极少被触发）。V3 文档 §10 的 Top2
邻域结论（略差）方向一致。

hl(4,3,2)  +20.57%/-24.54% | hl(6,4,2)  +27.31%/-22.81%

## R5 上涨共振窗 W ∈ {7,8,10,12,15}

```
W7 +29.61%/-24.38% | W8 +18.43%/-23.94% | W10(规格) +36.41%/-21.67%
W12 +25.50%/-21.35% | W15 +56.73%/-25.55%   （10bp 中位 total/dd）
```

判定：维持 W10。W15 中位 Δtotal +20.3pp（5/5 相位）真实存在，但中位 Δ回撤
−3.88pp，违反"不允许用回撤换收益"（Δdd ≥ −1pp）判据 → NEUTRAL(回撤代价)，
不采纳。W15 同时是网格边缘孤峰形态（W12 −10.9pp），双判据拦下。

## R6 领先指数收益窗 L ∈ {5,10,15,20}

```
L5 -4.66%/-37.40% | L10(规格) +36.41%/-21.67% | L15 +16.10%/-29.93% | L20 +5.34%/-30.52%
```

判定：维持 L10。L5/L15/L20 全 HARMFUL 且回撤大幅恶化（−8~−16pp）；
领先指数窗是全部轴中最敏感的参数，规格值 10 为唯一峰。

## R7 正收益过滤窗 P ∈ {2,3,5} + 形态复核扩展（P4/P7/P10）

```
P2 +34.02%/-25.65% | P3(规格) +36.41%/-21.67% | P5 +63.62%/-19.53%（Δ+27.2pp，5/5 相位，回撤改善+2.15pp）
形态复核：P4 +2.26%/-27.69% | P7 +14.72%/-23.19% | P10 +71.54%/-21.73%
```

判定：**维持 P3，P5 不采纳（孤峰）**。P5 通过 §二 全部三项数字判据
（ADOPT-CANDIDATE），但按预注册网格形态约束复核：相邻网格点 P4 Δ=−34pp、
P7 Δ=−49pp，均远劣于 −1pp 连续性门槛——响应面锯齿（+2%→+64%→+15%→+72%），
P5 为离散孤峰而非剂量-响应形态。且其增量集中于 2026（y2025 中位 +4.25% vs
规格 +16.81%），年度失衡佐证机制脆弱。**此例为形态约束的教科书案例：无该
约束则 +27pp/5/5 相位的"采纳候选"实为窗口长度的相位运气。**

## R8 最短持有期 H ∈ {2,3,5}

```
H2 +33.35%/-19.54%（变更 102）| H3(规格) +36.41%/-21.67%（84）| H5 +33.32%/-30.54%（62）
```

判定：维持 H3。H2 回撤改善 +2.1pp 但收益 −3.1pp 且 0/5 相位（换手 102 次，
成本敏感）；H5 收益近似、回撤恶化 −8.9pp。规格值帕累托最优。

## 小结

R1–R8 八轮、38 个网格点：**全部维持 V3 规格值，无采纳**。V3 的参数块
（止损 5%+cd1 / Top3 / 半衰期(5,3,2)@(2,4)% / 共振窗 10 / 领先窗 10 /
过滤窗 3 / 最短持有 3）在本机 529 概念数据、5 相位协议下逐轴复现为
局部最优——GPT 会话 2,457 组网格搜索的规格值具有跨数据集的稳健性
（这是比任何单项改动更强的证据）。
