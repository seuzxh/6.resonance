## 判定

**不采纳盘中粒度；维持收盘检查 T+1 执行。**

1. 预注册判据（R2 采纳需：中位 Δ回撤 ≥+1pp 且 Δ总收益 ≥−2pp 且 ≥4/5 相位
   回撤改善且分钟 vs 收盘有可分辨增量）：**全部未达**——分钟 vs 收盘同 x 的
   中位 Δtotal 为 −15.5~−32.2pp，中位 Δdd 为 −0.3~−5.6pp（无一改善）。
2. 机制解释：V3 为固定止损（自入场价），概念指数日内常击穿 5% 后收盘收回，
   盘中触发 = 在恐慌低点附近离场；收盘确认 + T+1 执行的"迟钝"恰是过滤器。
   与 dyn5 的 B4% 追踪止损结论相反但与其教训同构——**执行层风控的"更快"
   只在无止损栈上有效（dyn5 裸栈），V3 已有止损层，加快即功能挤占**
   （第三次同构证据，沿 memory minute-exec-layer-adopted）。
3. 稀释警示：分钟覆盖缺口致每相位中位 83~91 持仓日降级为收盘口径（400/529
   codes 覆盖）；若未来扩全覆盖可复验，但 −15pp 以上的收益差不太可能被
   稀释解释（降级日两模式行为一致，差异只来自有覆盖日）。
4. 附带复核：1 年窗上 x 网格收盘粒度再次确认 5% 为峰（x4/x6/x8 全差），
   与 R1 全窗结论一致。

生产栈不变：`{}`（V3 默认）。
