2. **基准日谜题已解**：锚点全A +38.01% 的窗口基准是 **2024-12-31 收盘**（本机精确复现

3. **⚠️ 重大稳健性警示（本机新发现）**：调仓网格相位敏感性极高。仅平移窗口起点

   锚点恰处最优相位。**+148.59% 不是稳健收益预期，是相位运气 + 幸存者目录下的
   上偏样本**；策略的真实信号强度应以宽基层（较稳、且为 GPT 会话自证的核心：
   "概念映射增益不显著 p=0.2659"）与显著性检验（p 刚过线）为准。
